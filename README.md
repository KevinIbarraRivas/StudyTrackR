# StudyTrackR

An iOS app that shows you how much you're actually studying. Pick a subject, start the timer, and when you're done the session gets saved with any notes you want to add. Over time you can see your stats by subject and figure out where your hours are really going.

Built with Swift and SwiftUI.

**📹 Watch the demo:** https://www.loom.com/share/5c475ce6a7ce4a54aa591ce4ad697641

## Features

- **Session timer** — pick a subject, start and stop the timer, and save the session when you're done
- **Notes** — add a note to any session to remember what you worked on
- **History** — scroll through every past session with its subject, time, and notes
- **Stats** — per-subject stat tracking so you can see how your study time breaks down
- **Four-tab navigation** — Home, Log Session, History, and Stats, each with its own icon
- **Motivational quotes** on the home screen to get you going

## Planned
